# APNN image assets

Add the two approved brand assets to this directory using the exact filenames:

- `logo.webp` — circular Ascension Parish News Now logo.
- `hero.webp` — wide APNN-branded hero/banner artwork.

GitHub: navigate to this `assets` directory, choose **Add file → Upload files**, drag in both `.webp` files from `APNN_GitHub_Pages_Ready/assets/`, then **Commit changes**.

The landing page already references `assets/logo.webp` and `assets/hero.webp` using relative links that work with both GitHub Pages preview and a custom domain.
